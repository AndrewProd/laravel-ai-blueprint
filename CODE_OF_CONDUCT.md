# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions focused
on the work. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainers through a
[private GitHub security advisory](https://github.com/AndrewProd/laravel-ai-blueprint/security/advisories/new)
or by contacting the repository owner on GitHub. Reports are handled confidentially.
